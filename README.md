# Create: Endergy

Take the power of your machines anywhere, even to other dimensions. Create: Endergy adds **endergy**, an energy born from the materials of the End that converts rotation into electricity and electricity back into rotation.

## Target

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.249 |
| Create | 6.0.10+ |
| Mod id | `create_endergy` |

## Building

Needs a JDK 21 on `JAVA_HOME`.

```
./gradlew build
```

The jar lands in `build/libs/`. `./gradlew runClient` starts a dev client with Create, Ponder, Flywheel and Registrate loaded.
